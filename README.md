# 线性代数 · 交互式可视化小工具

北京信息科技大学 · 线性代数课程配套的一组网页小工具，点开即用、无需安装，手机/平板/电脑均可打开。

在线地址：https://di-90.github.io/linalg-tools/

配套教材：同济大学《工程数学·线性代数》（第 7 版）前五章。每个工具均含「自由探索」与「练习」两种模式。

## 工具列表（按教材章节）

### 第一章 · 行列式

| 编号 | 工具 | 说明 |
|---|---|---|
| L16 | 逆序数与行列式定义 | 拖方块看逆序数与奇偶排列；骨牌演示行标、列标跟着元素一起走 |
| L2 | 行列式的几何意义 | 拖动两向量看有向面积 = \|A\|，理解定向与线性相关 |
| L15 | 克拉默法则 | 二元、三元实时算 D 与各 Dᵢ，得 xᵢ=Dᵢ/D；二元画直线、三元画平面看交点；D=0 时用秩判断 |

### 第二章 · 矩阵及其运算

| 编号 | 工具 | 说明 |
|---|---|---|
| L1 | 矩阵乘法 | 逐格高亮演示 C=AB 的“行 × 列”计算过程 |
| L3 | 二维线性变换 | 拖向量、调 2×2 矩阵，看 B=HA 与长度比 |
| L4 | 三维线性变换 | 3×3 矩阵作用于三维向量，可旋转/缩放场景 |

### 第三章 · 矩阵的初等变换与线性方程组

| 编号 | 工具 | 说明 |
|---|---|---|
| L14 | 逆矩阵 · 初等行变换求法 | 对 [A\|E] 逐步行变换，左块化为 E 时右块即 A⁻¹；变换顺序可不同，结果唯一 |
| L9 | 高斯消元与行阶梯形 | 逐步化行阶梯形/行最简形，给出秩与解的判定；“自己动手”模式自选行变换 |

### 第四章 · 向量组的线性相关性

| 编号 | 工具 | 说明 |
