# 线性代数 · 交互式可视化小工具

北京信息科技大学 · 线性代数课程配套的一组网页小工具，点开即用、无需安装，手机/平板/电脑均可打开。

在线地址：https://di-90.github.io/linalg-tools/

## 工具列表

### 核心概念（矩阵、行列式与线性变换）

| 编号 | 工具 | 说明 |
|---|---|---|
| L1 | 矩阵乘法 | 逐格高亮演示 C=AB 的“行 × 列”计算过程 |
| L2 | 行列式的几何意义 | 拖动两向量看有向面积 = det，理解定向与线性相关 |
| L3 | 二维线性变换 | 拖向量、调 2×2 矩阵，看 B=HA 与长度比 |
| L4 | 三维线性变换 | 3×3 矩阵作用于三维向量，可旋转/缩放场景 |
| L5 | 坐标与基变换 | 三点定义任意（可斜交）坐标系，可上传图片作底图 |

### 应用与拓展（变换的实际用途）

| 编号 | 工具 | 说明 |
|---|---|---|
| L6 | 二次型与二次曲面 | 调参观察椭球/双曲面/抛物面/马鞍面/锥面 |
| L7 | 机械臂 · 齐次变换连乘 | 旋转/平移写成矩阵连乘，动画演示末端轨迹 |
| L8 | 希尔密码 · 矩阵在密码学 | 密钥矩阵模 26 加解密，涉及行列式与模逆 |
